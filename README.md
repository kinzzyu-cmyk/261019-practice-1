# 관찰에서 변화로 · 디자인씽킹 웹 학습지

고등학교 디자인 수업을 위한 한국어 학습지입니다. 관찰 → 공감 → 원인 탐구 → 문제 정의 → 아이디어 발산 → 선정 → 구체화·검증 계획 → 성찰의 8단계로 구성됩니다.

## 실행 방법

`index.html`, `style.css`, `script.js`로 실행합니다. 외부 라이브러리, API, 빌드 과정이 필요하지 않습니다. 권장 실행 방법은 Python의 정적 파일 서버입니다.

```bash
cd /workspaces/261019-practice-1
python3 -m http.server 8000 --bind 0.0.0.0
```

브라우저에서 **http://localhost:8000**에 접속합니다. 원격 개발 환경에서는 포트 8000을 전달하세요. 서버 종료는 `Ctrl+C`입니다. `index.html`을 직접 열 수도 있지만, `file://`의 브라우저별 저장소 제한을 피하려면 HTTP 서버를 사용하세요.

### Streamlit으로 실행

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run streamlit_app.py
```

브라우저에서 **http://localhost:8501**에 접속합니다. 원격 개발 환경에서는 포트 8501을 전달하세요. `streamlit_app.py`는 같은 폴더의 HTML·CSS·JavaScript를 읽어 CSS·JS를 포함한 학습지를 표시합니다. 두 실행 방식은 동일한 학습지 코드를 사용합니다. `st.iframe`을 사용하는 Streamlit 1.66 이상이 필요합니다.

텍스트와 이미지는 Streamlit 서버가 아닌 학생의 브라우저에 저장됩니다. 정적 서버(8000)와 Streamlit(8501)은 접속 주소가 달라 저장 공간이 구분됩니다. 기존 작성 내용은 JSON 내보내기·불러오기로 옮기세요. 학습지 안의 **인쇄 / PDF** 버튼을 사용하면 iframe 안에서 전체 학습지를 인쇄합니다.

## 학생 사용 방법

1. 프로젝트명, 학급, 모둠명, 작성일을 입력합니다.
2. 단계 메뉴나 이전·다음 버튼으로 이동하며 기록합니다. 도움 질문과 접을 수 있는 예시는 참고용이며 답안에 자동 입력되지 않습니다.
3. 관찰한 사실과 해석, 조사로 확인한 사실과 추측을 구분합니다. 인터뷰 질문·답변은 필요한 만큼 추가합니다.
4. 아이디어 카드를 3개 이상 작성합니다. 카드는 추가·삭제할 수 있습니다. 작성한 카드 삭제에는 확인 창이 나옵니다.
5. 비교표는 앞 단계의 아이디어를 불러옵니다. 사용자 적합성·실현 가능성·기대 효과를 1~5점으로 평가하면 총점이 계산됩니다. 미평가는 0점이며 최종 아이디어는 학생이 직접 선택하고 근거를 씁니다. 이름을 바꿔도 기존 카드의 점수와 선택은 유지됩니다.
6. 해결방안을 구체화하고 스케치, 준비물, 실행 순서, 피드백 계획, 성공 기준과 검증 전 예상 효과를 작성합니다. 스케치와 실제 검증 결과는 선택입니다. PNG/JPG/WebP/GIF 이미지를 최대 10MB까지 첨부할 수 있습니다.
7. 진행률은 기본 정보와 기록·평가·점검 여부를 나타냅니다. 답변의 질을 평가하지 않으며 이미지와 실제 검증 결과는 제외됩니다. 아이디어를 추가하면 전체 항목 수도 늘어납니다. 미작성 항목이 있어도 자유롭게 이동할 수 있습니다.
8. 수업 종료 전 **내보내기**로 JSON 백업을 보관합니다. 텍스트, 점수, 선택, 인터뷰, 스케치가 모두 포함됩니다. **불러오기**는 형식을 검사한 뒤 확인을 받고 현재 학습지를 교체합니다. 최대 25MB의 이 학습지 JSON을 지원합니다.

## 저장과 개인정보

- 텍스트와 선택값은 입력 즉시 `localStorage`에, 스케치는 `IndexedDB`에 자동 저장·복원됩니다.
- 현재 기기·브라우저·접속 주소(프로토콜, 호스트, 포트)에만 저장됩니다. 다른 브라우저, 다른 포트, 다른 주소에서는 자동으로 이어지지 않습니다.
- 비공개 모드 종료, 사이트 데이터 삭제, 저장 공간 정리로 데이터가 사라질 수 있습니다. 저장 실패 알림이 나오면 JSON으로 내보내세요. 이미지 저장에 실패해도 현재 화면에 읽힌 이미지는 JSON 내보내기에 포함됩니다.
- 모둠당 한 브라우저 탭에서 작성하세요. 여러 탭의 충돌 조정이나 실시간 공동 편집 기능은 없습니다.
- 파일은 서버나 외부 API로 전송하지 않습니다. 학생용 AI 자동 답변 기능은 없습니다. 인터뷰에는 실제 이름 대신 역할·별칭을 쓰는 것을 권장합니다.
- 전체 초기화는 확인 후 텍스트와 첨부 이미지를 삭제합니다. 공용 기기에서는 JSON을 보관한 다음 초기화하세요.

## 인쇄 및 PDF

- **인쇄 / PDF → 작성본 인쇄**: 현재 단계와 무관하게 전체 8단계, 인터뷰, 모든 아이디어, 점수, 선택과 스케치를 출력합니다. 접힌 예시나 화면 표시 여부가 학생 답변의 출력에 영향을 주지 않습니다.
- **빈 학습지 인쇄**: 학생 답변과 이미지를 제외한 기본 양식, 빈 인터뷰 1개, 빈 아이디어 카드 3개를 출력합니다. 저장된 작성 내용은 바뀌지 않습니다.
- A4 세로 인쇄에 맞춰 별도 출력 레이아웃을 생성합니다. 긴 답변은 줄바꿈·페이지 나눔되며 입력칸 높이로 잘리지 않습니다. 메뉴와 버튼은 제외됩니다.
- 브라우저 인쇄 창에서 A4·세로 방향과 PDF 저장을 선택할 수 있습니다. 브라우저 머리글/바닥글은 필요에 따라 끄세요. `Ctrl+P` / `Cmd+P`는 작성본을 인쇄합니다.

## 확인 방법

단계 이동 후 되돌아오기, 입력 후 새로고침, 인터뷰·아이디어 추가와 삭제, 점수 변경과 직접 선택을 확인합니다. 이미지 첨부 후 새로고침하여 복원되는지 확인하고 JSON 내보내기 → 초기화 → 불러오기로 이미지와 답변이 돌아오는지 확인합니다. 인쇄 미리보기에서 작성본·빈 양식, 긴 답변과 전체 8단계가 보이는지 확인합니다.

## 실제 검증 결과

2026-10-19, 로컬 HTTP 서버와 headless Chromium 130에서 다음 항목을 확인했습니다. 테스트 도구는 임시 경로에만 설치했으며 학습지 실행에는 필요하지 않습니다.

- 초기 화면, 8단계 직접 이동, 이전·다음, 미작성 안내, 단계 간 답변 유지
- 텍스트·선택·점수의 저장과 새로고침 복원, 인터뷰 추가·삭제, 예시가 답변을 채우지 않음
- 아이디어 기본 카드 3개와 추가·삭제, 이름 변경의 비교표 반영, 점수 5+4+3=12 자동 계산, 자동 선택 없이 학생의 직접 선택 유지
- 스케치의 실제 IndexedDB 저장과 새로고침 복원
- 이미지·답변·점수를 포함한 JSON 다운로드, 확인 후 전체 초기화, JSON 불러오기 및 다시 새로고침한 뒤 복원
- 잘못된 JSON 거부와 기존 데이터 보존
- 작성본·빈 학습지 인쇄 요청이 생성한 출력 DOM의 구분, 전체 8단계와 화면 밖 답변 포함, 작성 데이터 보존
- 인쇄 요청에서 얻은 DOM과 실제 CSS로 A4 PDF 생성: 120줄 답변을 포함한 작성본 10쪽에서 답변의 마지막 표식, 성찰 답변과 첨부 이미지를 확인
- 1440px 데스크톱 화면, 768px 태블릿·390px 모바일 화면의 가로 넘침 없음, 입력 요소의 접근성 레이블
- 저장 공간 부족 오류를 주입했을 때 실패 알림과 메모리 답변의 JSON 백업, 브라우저 JavaScript 오류 없음

**확인하지 못한 항목:** 실제 프린터 출력, 운영체제의 인쇄 대화상자 조작, Safari·Firefox, 실제 태블릿·휴대전화의 터치 및 보조기기 사용. 인쇄 버튼의 `window.print` 호출은 테스트에서 출력 DOM을 캡처하는 함수로 대체했고 PDF는 headless 출력으로 확인했습니다.

### Streamlit 추가 검증

Streamlit 1.66.0의 실제 iframe을 Chromium으로 열어 학습지 표시, 단계 이동, 입력 후 새로고침 복원, 아이디어 추가·삭제, 점수 합산과 직접 선택을 확인했습니다. IndexedDB 이미지 복원, 이미지가 포함된 JSON 다운로드·불러오기, 작성본·빈 학습지의 인쇄용 DOM 구분도 확인했습니다. 390px 모바일 화면에서 바깥 화면과 iframe 모두 가로 넘침이 없었고 JavaScript 오류가 없었습니다. Streamlit에서도 실제 프린터·인쇄 대화상자 조작은 확인하지 않았습니다.
